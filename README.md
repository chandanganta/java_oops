# Bank Account Management System

A simple Java program that demonstrates classes and objects through a basic bank account management system.

## Features
- Create bank accounts using a parameterized constructor.
- Deposit money into an account.
- Withdraw money with an insufficient balance check.
- Check the current account balance.
- Display account details.
- Manage two accounts independently.

## How to Run

1. Compile the Java file:
   `javac BankAccountManagement.java`
2. Run the program:
   `java Main`

## Concepts Used
- Classes and Objects
- Constructors
- Methods
- Encapsulation
- Independent object data
